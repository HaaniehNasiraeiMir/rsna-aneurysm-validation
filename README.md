# Beyond Overall AUC: Anatomy- and Modality-Specific Performance and Calibration of Deep Learning for Intracranial Aneurysm Detection Using the RSNA 2025 Dataset

## Primary Research Question
Does deep-learning performance and calibration for intracranial aneurysm detection vary across imaging modalities and cerebrovascular anatomical locations?

## Secondary Questions
- Which anatomical locations have the poorest detection performance?
- Does performance differ across CTA, MRA, T1-postcontrast MRI, and T2 MRI?
- Is model calibration worse in particular modalities or anatomical locations?
- Which subgroups contribute disproportionately to false-negative predictions?

## Dataset
RSNA 2025 Intracranial Aneurysm Detection dataset.

## Current Status
Study development and feasibility assessment.

## Planned Workflow
Literature review → dataset audit → exploratory analysis → model evaluation → subgroup analysis → calibration analysis → failure analysis → manuscript preparation.

## Data Note
Raw RSNA imaging data will not be stored in this public repository. This repository will contain code, documentation, analysis workflows, and shareable results only.
